# Wonderlab Login/Register UI

This project is a static front-end for a toy shop authentication flow.

## Included pages
- `index.html` — landing page
- `login.html` — sign-in form
- `register.html` — sign-up form
- `auth.css` — shared styling for auth pages
- `auth.js` — client-side validation and password toggle

## Run locally
From the project root, start a local web server:

```bash
python -m http.server 4180
```

Then open:
- http://localhost:4180/index.html
- http://localhost:4180/login.html
- http://localhost:4180/register.html

## Notes
This is a UI demo only. The forms validate input on the front end, but they do not connect to a real backend or database yet.
